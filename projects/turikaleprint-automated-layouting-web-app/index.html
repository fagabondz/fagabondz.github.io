Ikhtisar Eksekutif

Platform cetak foto digital yang menjembatani pelanggan dan mesin produksi secara real-time. Fokus utamanya adalah memangkas waktu layouting (potong foto, ganti background, susun ukuran kertas) yang sebelumnya menjadi bottleneck karena dilakukan manual oleh operator.

01 / Situasi

Situation

Saat mengikuti program magang nasional di TurikalePrint, saya menemukan bottleneck operasional yang sangat repetitif. Admin harus mengunduh foto pelanggan, menghapus background secara manual untuk pas foto, membuka Photoshop, mencari template ukuran kertas, lalu menyusun letak foto satu per satu. Proses ini tidak hanya lambat, tetapi juga menciptakan ketergantungan karena mewajibkan setiap admin memiliki skill Photoshop.

02 / Tugas & Analisis

Task

Pekerjaan berulang ini memunculkan satu pertanyaan: Bagaimana cara meringkas alur kerja ini agar admin tanpa pengalaman editing atau desain grafis pun bisa mencetak foto dengan cepat? Analisis menunjukkan bahwa keharusan berpindah antara WhatsApp, browser, dan software desain yang berat (Photoshop) adalah sumber inefisiensinya.

03 / Tindakan & Solusi

Action

Saya membangun aplikasi web terpusat untuk menggantikan peran Photoshop dalam proses layouting. Sistem ini mengotomatisasi penyusunan ukuran foto ke dalam kanvas. Untuk menghilangkan kebutuhan editing eksternal, saya mengintegrasikan fitur manipulasi gambar langsung di dalam web—seperti penghapusan latar belakang dan penyuntingan manual menggunakan SDK pemrosesan gambar (imgly)—sehingga admin bisa mengedit dan menyusun foto dalam satu layar.

04 / Arsitektur Sistem

Arsitektur Sistem

Arsitektur modular yang sangat ringan dengan rendering kanvas berpusat di sisi browser (Client-side). Server lokal hanya bertugas mengelola antrean pesanan secara asinkron untuk memastikan respons sistem tetap instan tanpa membebani memori komputer toko.

07 / Detail Teknis & Retrospektif
Tantangan & Hambatan Teknis

Tantangan teknis terbesar adalah menghadirkan fitur editing manual (seperti alat kuas penghapus dan pengembali piksel) di atas kanvas web agar tetap stabil. Memproses manipulasi gambar beresolusi tinggi di sisi browser rentan menyebabkan crash atau memory leak, sehingga saya harus memastikan integrasi library image processing berjalan sangat optimal tanpa error.

Pembelajaran & Catatan Teknis
  • Fokus selesaikan masalah operasional harian kasir, hindari membangun fitur kompleks yang tidak mereka butuhkan.
  • Optimasi garbage collection pada JS Canvas sangat penting untuk mencegah lambatnya browser saat mengedit foto resolusi tinggi.
Rencana Pengembangan (Roadmap)
  • Migrasi database bertahap ke layanan cloud agar pemilik bisa memantau pesanan jarak jauh.
  • Menambahkan AI deteksi wajah untuk otomatisasi cropping pas foto.
